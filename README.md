# qa-api-test-automation
API test automation framework using Postman, Newman and CI/CD
## 🛠️ Stack Tecnológica & Diferenciais
- **Automação de API:** Postman & Newman.
- **BDD (Behavior Driven Development):** Documentação técnica em Gherkin (.feature).
- **CI/CD Pipeline:** GitHub Actions executando testes em cada Push.
- **Relatórios Executivos:** Geração de relatórios HTML (Newman HTML Extra) armazenados como Artifacts no GitHub.
- **Tratamento de Erros:** Cobertura de cenários de sucesso (200, 201) e cenários negativos (404).
